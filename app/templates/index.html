Latest completed focus Checking

Button logic: creates one event for the latest completed work session. It does not export breaks, does not run automatically, and blocks a second event for the same session.

Where to check: open the shared Google Calendar and find the “Pomodoro focus session” event at the completed session time.

Required for Calendar sync

Set up once, then use the button

  1. In Google Calendar open Settings and sharing → Integrate calendar and copy Calendar ID (recommended). An official Google Calendar embed URL also works when it contains the src parameter.
  2. Put that value in GOOGLE_CALENDAR_ID and one-line service-account JSON in GOOGLE_CALENDAR_CREDENTIALS_JSON inside server .env.
  3. Share the calendar with the service account’s client_email and allow it to make changes to events.
  4. Restart Flask, complete one focus interval, then click Sync to Google Calendar.

Optional GOOGLE_CALENDAR_EVENT_PREFIX and event color only customize the event.

Google Sheets

Optional

Export completed focus sessions as rows

Checking

Copy only the value between /d/ and /edit in the Google Sheets URL, not the whole URL.
Service-account credentials on Flask server Checking

Save Settings: validates the enabled setup and stores only the switch and Spreadsheet ID in SQLite. It sends no rows to Google.

Sync Completed Sessions: reads completed work records, creates the A:I header if needed, and appends only Session IDs that are not already present.

Loading Google Sheets settings.

Required only after enabling

From Google Cloud to the spreadsheet

  1. Enable Google Sheets API and create a service account in Google Cloud.
  2. Create its JSON key and keep that file outside the repository.
  3. Share the target spreadsheet with the JSON client_email as Editor.
  4. Put compressed one-line JSON in GOOGLE_SHEETS_CREDENTIALS_JSON, set GOOGLE_SHEETS_ENABLED=true, and restart Flask.
  5. Enter the Spreadsheet ID here, click Save Settings, then Sync Completed Sessions.

Where to check: the first worksheet receives columns A:I. Run sync twice—the second run should report duplicates as skipped, without extra rows.

Safe when off With Sheets disabled, credentials and Spreadsheet ID stay unvalidated and no Google client or network request is created.

How it works

Timer logic

  • The active timer is stored in `localStorage`, so a page reload does not destroy the current session.
  • Completed work, short break, and long break sessions are saved through Flask API into the database.
  • Daily, weekly, and monthly hours are calculated from stored database sessions.
  • Settings control durations, auto-start for the next session, and the long-break interval.
