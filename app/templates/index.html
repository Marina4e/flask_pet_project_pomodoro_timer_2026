How it works

Timer logic

  • The active timer is stored in `localStorage`, so a page reload does not destroy the current session.
  • Completed work, short break, and long break sessions are saved through Flask API into the database.
  • Daily, weekly, and monthly hours are calculated from stored database sessions.
  • Settings control durations, auto-start for the next session, and the long-break interval.
